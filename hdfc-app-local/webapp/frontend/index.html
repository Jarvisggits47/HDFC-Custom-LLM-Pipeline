How this works

This app runs a real, free, local open-weights model — no API key, no per-token cost, nothing leaves your machine. Upload a policy PDF (or paste text) and it's chunked and scanned for PII before storage. "Adaptation" builds a small phrasing-style system prompt plus a real TF-IDF search index over your documents — the same kind of vector-search approach production RAG systems use, just running locally instead of on a hosted vector database. Every playground question triggers live retrieval — the top-matching chunks for that exact question are pulled fresh and injected into the prompt, not dumped statically. The evaluation gate calls the local model twice per test case — once with no banking context, once through your adapter — and scores the actual generated text.

Dataset governance

Register a source, review its records, and approve an immutable version before it can be used in a run.

Adaptation runs

Builds a grounded system-prompt adapter from an approved dataset. Real, live process — not simulated.

Evaluation & release gate

Calls the live model with and without your adapter for each banking test case, and blocks release on any critical failure.

Model registry

Signed, versioned entries linking each release to its adapter, evaluation evidence, and owner.

Deployment control plane

Canary traffic, expansion, and rollback for promoted models.

Integration playground
